# AE370 Orbital Perturbations

This is the github repository for the first AE370 group project of Lyn Anderson, Margot DeLaTorre, Matthew Giraldo, and Nathan
Szymanski.


## Requirements
AE370 default kernel with Python 3.12.14. SymPy installed in addition. 

## Units

To minimize numerical error and the simplicity of interfacing with other programs, the following units have been chosen:

- Kilometers
- Kilograms $\cdot\space10^{24}$
- Seconds

## Data
Planet positions and velocities are from JPL Horizons (https://ssd.jpl.nasa.gov/horizons/app.html), for 2026-01-01 00:00:00.
